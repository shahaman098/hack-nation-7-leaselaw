# Build with DataHub: The Agent Hackathon

Build AI agents with DataHub's context graph that do real work.

## Official theme
Agents that use DataHub's context graph to do real work — and write back to it.
Projects should go beyond reading metadata and contribute back to the graph.
Projects should clearly go beyond features DataHub already provides out of the box.

## Tracks
- Agents That Do Real Work
- Metadata-Aware Code Generation & Development
- Production ML Agents
- Wildcard

## Required / encouraged technology
- Required: meaningful use of DataHub (read context via MCP / Agent Context Kit / APIs and write findings back into the graph)
- Encouraged: GitHub Actions, dbt/SQL pipelines, MLflow, OSS contribution to DataHub

## Judging criteria
- Use of DataHub (high): reading metadata is not enough; write-back to the graph is rewarded
- Technical Execution (high): end-to-end, verifiable demo
- Originality (high): must go beyond features DataHub already ships (Ask DataHub, Analytics Agent, AI documentation)
- Real-World Usefulness (high): solves a painful practitioner workflow
- Submission Quality (medium): README, demo video, screenshots/examples

## Bonus
- Meaningful OSS contribution to DataHub (for example datahub-skills or docs)

## Submission requirements
- Working demo (footage or live)
- Public GitHub repository with Apache 2.0 LICENSE at repo root
- Demo video under 3 minutes, public
- Devpost project submission form completed

## Constraints
- Team size: 1–4
- Build window remaining: about 24 hours to deadline Mon 10 Aug 2026, 22:00 BST
- Participants observed: ~2901 registrants

## Crowded / do-not-build ideas
- Chat-with-your-catalog wrappers
- Auto-documentation agents that rebuild DataHub AI docs
- Generic NL-to-SQL assistants
- Metadata quality scorecards without action
- Schema-drift alerters that only notify and do not act
- Rebuilding Ask DataHub / Analytics Agent

## Prizes
- Grand prize and honourable mentions
- Feedback survey prize (opt-in)
