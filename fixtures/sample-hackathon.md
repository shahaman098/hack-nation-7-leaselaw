# Sample Civic Resilience Hackathon 2026

Build tools that make public services more reliable, fair, and understandable.

## Tracks
- Civic Data
- Accessibility
- Public Admin Tooling

## Sponsors
- Example Cloud (managed Postgres, object storage, serverless functions)
- Open Data Alliance

## Judging criteria
- Technical implementation (high)
- Real-world applicability (high)
- Originality (medium)
- Design and demo clarity (medium)

## Rules
- Teams of 1–4
- 48-hour build window
- Working demo required (footage or live)
- Open government datasets encouraged
- Sponsor tech is optional but rewarded when materially useful

## What we do not want
- Chatbot wrappers
- Dashboard-only visualisations without action
- Generic productivity assistants
